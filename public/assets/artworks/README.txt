Обработанные WebP фотографии работ хранятся в этой папке и собираются в
репозиторий вместе с сайтом.

Для повторного импорта числовых JPEG/JPG используйте:
  npm run import:gallery -- "путь/к/папке"

Каталог `src/data/artworks.json` содержит категории, названия и связи главных
снимков с дополнительными ракурсами. После импорта запустите `npm run build`.
